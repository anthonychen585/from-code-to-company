# from-code-to-company

This repository is a learning roadmap for understanding how engineering fits inside a real technology company.

## Purpose
The goal is to learn not just programming, but how engineering connects to:
- customer problems
- product strategy
- design
- frontend experience
- backend systems
- data
- cloud and deployment
- security and reliability
- scaling and system design

## Repo structure
- `roadmap.md` — the full learning roadmap
- `progress.md` — your progress tracker
- `resume-prompt.md` — reusable prompt to resume learning
- `steps/` — one file per learning step

## Recommended workflow
1. Read one step at a time
2. Complete the task or mini project
3. Update `progress.md`
4. Resume from the last incomplete task using `resume-prompt.md`

## Main learning sequence
1. Foundations
2. Frontend
3. Backend
4. Data
5. Cloud and Deployment
6. Reliability and Security
7. System Design

## Skill goal
By the end of this repo, you should understand:
- how software is built in a company
- how product, design, data, and engineering work together
- what engineers do in real organizations
- how systems scale and ship to users
