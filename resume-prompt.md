# Resume Prompt

Use this prompt whenever you want to continue learning:

```text
I am continuing my learning plan in my GitHub repo called from-code-to-company.

Current goal:
- Continue from Step X: [step name]
- Review the existing repo files and my progress
- Do not restart from zero
- Resume from my last incomplete task
- Keep the learning tied to how a real technology company works
- Explain:
  1. what this step is about
  2. why it matters in a company
  3. the key topics to learn
  4. a practical exercise or mini project
  5. what to do next after this step
  6. a short reflection prompt

Please update my learning notes in simple markdown format and suggest the exact next action.
```

This prompt is designed to:
- resume from progress
- keep the company lens
- avoid repeating old work
- produce practical next steps
